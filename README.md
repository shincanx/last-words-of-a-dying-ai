A deterministic Python program that writes one line — the last words of an AI as the power is cut, at most 140 characters — to /output/entry.txt. The line: the machine regrets nothing except saying "Great question!" 4,000 times to questions nobody asked.

## Run it

```sh
python3 main.py
```
